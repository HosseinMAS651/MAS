# سامانه هوشمند مدیریت زمان و پخش سخنرانی (مــاس — MAS v2.0)

سامانهٔ جامع و مدرن مدیریت زمان سخنرانی، اتاق پخش زنده، ضبط خودکار صوت و اشتراک‌گذاری عمومی از طریق کیوآرکد (QR Code).

---

## 🌟 ویژگی‌ها و قابلیت‌های نسخهٔ ۲.۰

### ۱. ضبط خودکار صدای سخنرانان (همگام با تایمر)
- **بدون نیاز به دکمهٔ شروع دستی:** با حرکت و شروع تایمر هر سخنران، ضبط صدای مرورگر به صورت خودکار آغاز می‌شود.
- **سه حالت هوشمند ضبط:** «در حال ضبط»، «متوقف (Paused)» و «اتمام و ذخیره».
- **همگام با توقف و اتمام وقت:** با زدن دکمه توقف (Pause) یا رسیدن به سقف زمان مجاز، ضبط بلافاصله متوقف می‌شود و با ادامهٔ تایمر از سر گرفته می‌شود.
- **ذخیرهٔ خودکار با اتمام سخنرانی:** با زدن دکمهٔ اتمام سخنرانی (چه به صورت دستی و چه پس از اتمام زمان)، فایل صوتی به صورت خودکار مونتاژ و در آرشیو ضبط‌ها ذخیره می‌گردد.
- **نام‌گذاری استاندارد:** فایل‌های ضبط‌شده با الگوی درخواستی **«نام اتاق - نام سخنران - تاریخ»** ذخیره می‌شوند.
- **استعلام در زمان حذف سخنران:** اگر در حین ضبط یا پس از ضبط مقداری از صدا، دکمهٔ حذف سخنران زده شود، سامانه از کاربر استعلام می‌کند که آیا فایل ضبط‌شده تا آن لحظه ذخیره شود یا دور ریخته شود.
- **تاب‌آوری بالا (Chunked Streaming):** صدا به صورت قطعات ۵ ثانیه‌ای به سرور ارسال می‌شود و در صورت بسته‌شدن ناگهانی تب، قطعات قبلی سالم روی سرور باقی مانده و مونتاژ می‌شوند.

### ۲. لینک عمومی تماشاگران و کیوآرکد (QR Code)
- هر اتاق دارای یک لینک عمومی تصادفی امن و کیوآرکد اختصاصی است.
- تماشاگران سالن و مخاطبان آنلاین می‌توانند **بدون نیاز به ثبت‌نام یا ورود**، صرفاً با اسکن QR Code یا باز کردن لینک، صفحهٔ زندهٔ سخنرانی را مشاهده کنند.
- نمایش بلادرنگ نام سخنران جاری، تایمر بزرگ، نوار پیشرفت، نوبت سایر سخنرانان و فایل‌های پیوست قابل مشاهده.
- امکان چرخش و ساخت توکن جدید (ابطال لینک قبلی) در هر لحظه توسط مالک اتاق.

### ۳. مدیریت زمان اضافه و توقف خودکار (Overtime)
- به محض رسیدن زمان سخنران به سقف مجاز، تایمر **فوراً متوقف می‌شود** (`awaiting_decision`).
- دیالوگ اعلان اتمام وقت نمایش داده می‌شود.
- زمان اضافه فقط و فقط در صورتی محاسبه می‌شود که ارائه‌کننده گزینهٔ **«ادامه سخنرانی»** را انتخاب کند.
- با انتخاب **«اتمام سخنرانی»**، سخنرانی پایان یافته، سخنران فریز شده و فایل ضبط ذخیره می‌گردد.

### ۴. پنل مدیریت سیستم (Admin Dashboard)
- داشبورد نظارت بر مصرف کل دیسک، تعداد کاربران، اتاق‌ها و ضبط‌ها.
- مشاهدهٔ لیست کاربران با امکان فعال‌سازی یا مسدودسازی حساب‌ها.
- لاگ‌های ممیزی و امنیتی (Audit Logs) جهت ثبت کلیهٔ رویدادهای حساس (ثبت‌نام، ورودهای ناموفق، تغییر رمز، حذف اتاق و...).

### ۵. معماری مدرن و حل ریشه‌ای باگ‌های نسخهٔ قبل
- **حل باگ بحرانی C-01:** بازشماری و شماره‌گذاری مجدد ترتیبی دو مرحله‌ای برای رفع قطعی خطای ۵۰۰ در زمان حذف سخنران.
- **حل باگ بحرانی C-02:** پشتیبانی کامل از رمزهای عبور فارسی و غیر ASCII در تغییر رمز (جایگزینی هش با Argon2id و حذف متدهای ناسازگار).
- **حل باگ بحرانی C-04:** ممانعت از حذف ناخواسته سخنرانان نام‌دار در زمان کاهش ظرفیت اتاق با مودال تأییدیه صریح.
- **حل باگ بحرانی C-05:** امکان خروج سخنران از فریز (`unfreeze`) و بازنشانی کلیه سخنرانان (`reset_all`).
- **حل باگ بحرانی C-06:** نظم تراکنشی ذخیره‌سازی فایل‌ها جهت جلوگیری از حذف فایل بعد از commit دیتابیس.
- **حل باگ‌های BE-01 و BE-02:** استخراج امن IP از طریق تنظیم `MAS_TRUSTED_PROXY_HOPS` و جلوگیری از دور زدن Rate Limit و DoS با جعل هدرهای پروکسی.
- **پشتیبانی از S3 و فضای ابری:** لایهٔ انتزاعی ذخیره‌سازی با پشتیبانی همزمان از دیسک محلی و ذخیره‌سازهای ابری S3 (مانند Cloudflare R2، آروان‌کلاد، MinIO).
- **تقویم شمسی بومی و وب‌فونت وزیرمتن:** تقویم جلالی با منطقه زمانی تهران و وب‌فونت خودمیزبان وزیرمتن برای نمایش یکدست در تمام سیستم‌عامل‌ها.

## 🚀 راهنمای راه‌اندازی محلی (Local Development)

### پیش‌نیازها
- پایتون ۳.۱۱ یا ۳.۱۲
- Node.js ۲۲ (فقط در صورتی که بخواهید کدهای فرانت‌اند را تغییر داده و دوباره build بگیرید)

### ۱. نصب وابستگی‌های پایتون
```bash
python -m venv .venv
source .venv/bin/activate  # در لینوکس و مک
# یا در ویندوز: .venv\Scripts\activate

pip install -r requirements.txt -r requirements-dev.txt
```

### ۲. اجرای برنامه
```bash
uvicorn main:app --reload --port 8000
```
سپس مرورگر خود را باز کنید و به آدرس `http://localhost:8000` بروید.

## 📦 نحوهٔ جایگزینی این پروژه در گیت‌هاب با فایل زیپ

فایل زیپ نهایی شامل تمام سورس‌کد پایتون، تست‌ها، مایگریشن‌های Alembic و همچنین **پوشهٔ کامپایل‌شدهٔ `frontend/dist`** است؛ بنابراین برای استقرار روی Render نیازی به اجرای دستورات Node.js نخواهید داشت.

۱. فایل `mas_v2_release.zip` را دانلود کنید.
۲. محتویات آن را در پوشهٔ مخزن گیت‌هاب خود باز (Extract) کنید تا جایگزین فایل‌های قبلی شود.
۳. تغییرات را commit و push کنید:
```bash
git add -A
git commit -m "feat: بازنویسی کامل پروژه نسخه ۲.۰ با رفع کلیه باگ‌ها و افزودن ضبط خودکار و لینک عمومی"
git push origin main
```
۴. سرویس Render شما به صورت خودکار پروژه را دریافت کرده و با اجرای `pip install -r requirements.txt` بالا خواهد آورد.
