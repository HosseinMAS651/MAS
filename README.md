# ماس — مدیریت اتاق سخنرانی

این نسخه یک وب‌اپلیکیشن واقعی FastAPI است و منطق اصلی را روی Backend و دیتابیس نگه می‌دارد؛ تایمر اتاق فقط یک شمارنده نمایشی در مرورگر نیست.

## قابلیت‌های پیاده‌سازی‌شده

- ثبت‌نام با نام کاربری انگلیسی/عدد/_ و رمز عبور
- ورود با Session تصادفیِ قابل ابطال، انقضا و کوکی HttpOnly
- محافظت CSRF برای عملیات تغییر‌دهنده
- تکمیل پروفایل در ورود اول و ویرایش بعدی
- صفحه خانه، پروفایل، اتاق‌ها و صفحه غیرفعال فایل‌های ضبط‌شده
- ایجاد، ویرایش و حذف اتاق
- تعریف ظرفیت ۱ تا ۱۰۰ سخنران
- نام، جنسیت، سن، توضیحات و زمان هر سخنران
- زمان همگانی یا اختصاصی
- ذخیره انتخاب ضبط و نمایش زنده فایل
- آپلود فایل همگانی یا اختصاصی هر سخنران با سقف حجم و whitelist پسوند
- حذف واقعی فایل از دیتابیس و دیسک
- ترتیب بر اساس سن، الفبا، تصادفی و دستی
- جابه‌جایی سخنران‌ها با Drag & Drop برای ترتیب دستی
- صفحه پخش واقعی اتاق
- تایمر روی Backend: شروع، توقف، بازیابی، زمان اضافه و قبلی/بعدی
- API وضعیت اتاق برای همگام‌سازی مرورگرها
- ضبط صوت از میکروفون مرورگر و آپلود فایل ضبط‌شده (در صورت فعال بودن ضبط)
- Health check در `/health`
- پشتیبانی از SQLite برای شروع و PostgreSQL از طریق `DATABASE_URL`
- Dockerfile برای استقرار ساده

## اجرای محلی

Python 3.11 یا 3.12 پیشنهاد می‌شود.

```bash
python -m venv .venv
# Windows
.venv\\Scripts\\activate
# Linux/macOS
source .venv/bin/activate
pip install -r requirements.txt
```

یک Secret واقعی بساز و در محیط قرار بده:

Windows PowerShell:
```powershell
$env:MAS_SECRET_KEY="یک-رشته-تصادفی-طولانی-حداقل-۳۲-کاراکتر"
python -m uvicorn main:app --reload
```

Linux:
```bash
export MAS_SECRET_KEY="یک-رشته-تصادفی-طولانی-حداقل-۳۲-کاراکتر"
uvicorn main:app --host 0.0.0.0 --port 8000
```

سپس:
`http://127.0.0.1:8000/login`

## استقرار واقعی

برای نمونه کوچک می‌توان SQLite را نگه داشت، اما برای استفاده چندکاربره بهتر است PostgreSQL تنظیم شود:

```text
DATABASE_URL=postgresql+psycopg://USER:PASSWORD@HOST:5432/mas
```

برای HTTPS، reverse proxy مثل Nginx/Caddy و گواهی TLS استفاده کن و:

```text
MAS_COOKIE_SECURE=1
```

را فعال کن.

## نکته مهم درباره فایل و ضبط

فایل‌های آپلودشده فعلاً روی دیسک همان سرور نگهداری می‌شوند. در مقیاس بالاتر بهتر است storage آبجکتی مانند S3/MinIO اضافه شود. ضبط صوت مرورگر نیاز به اجازه میکروفون و HTTPS در محیط عمومی دارد.

## نکات Production

- Secret را داخل کد قرار نده.
- PostgreSQL و Backup منظم برای محیط واقعی ترجیح داده می‌شود.
- پوشه `uploads` باید روی volume دائمی باشد.
- برای چند سرور، Rate Limit و Session Store را از حالت حافظه محلی به Redis/سرویس مشترک منتقل کن.
- قبل از انتشار عمومی، تست امنیت، لاگینگ، مانیتورینگ، Backup/Restore و سیاست نگهداری فایل را اضافه کن.
